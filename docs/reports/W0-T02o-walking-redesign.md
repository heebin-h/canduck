# W0-T02o — 실제 보행 전환 재설계 (휠+스윙 → 2-DOF 실보행)

> 작성: 2026-11-10 · 상태: **설계 결정 문서 (부품 미결제, 실측 전)** · 브랜치: `w0/t02o-walking-redesign`
> 진행 체크리스트: `docs/roadmap.md` § "W0-T02o 실보행 전환"

## 0. 결론

- **보행 방식**: roadmap W8 옵션 A/B/C 대신 **D. 2-DOF/다리 실보행(waddle)** 으로 확정 — 다리당 고관절 yaw + 발목 roll. 몸을 좌우로 기울여 한 발을 띄우고 고관절 yaw로 내딛는다. (heebin 결정, 2026-11-10)
- **크기**: 전체 높이 **~30cm** 기준(설계 변수). 하한은 RPi4(85×56mm) + HAT 스택이 몸통에 들어가는 폭.
- **다리 서보 4개는 25kg·cm급 표준 사이즈로 교체**, 머리·팔 6개는 MG90S 유지.
- **N20 휠·TB6612FNG 삭제.**
- **전원에 다리 전용 고전류 레일(6V_LEG, ≥12A peak)을 추가**하고, 이동·보행 시험부터는 **배터리 보류를 해제**한다.
- **3D 출력은 보유 Bambu Lab P1S로 내재화**한다(외주 삭제). 골격은 PETG, 외피는 PLA, 발바닥은 TPU.

## 3. 토크 산정 (추정 — 실측으로 갱신 필요)

**질량 가정 1.8kg (설계값)** 의 내역(전부 추정):

| 부품 | 질량 |
|---|---|
| RPi4 + 방열 | ~70g |
| PCB 2장 + 벅 | ~80g |
| 2S 5000mAh | ~280g |
| MG90S ×6 | 80g |
| 25kg 서보 ×4 | ~260g |
| 골격 + 외피 | ~500g |
| 배선 | ~60g |
| 3-in-1 카메라 | **미확인** |
| 소계 (카메라 제외) | ~1.33kg |

카메라와 마진을 포함해 1.8kg으로 잡았다.

- **발목 roll** (가장 큰 부하): 몸 전체를 기울이며 무게중심을 지지발 위로 옮긴다.
  `τ = m·g·d = 1.8 × 9.81 × 0.04 ≈ 0.71 N·m ≈ 7.2 kg·cm` (d = 무게중심과 발목축의 수평 거리 4cm 가정)
  동적 여유 ×2.5 → **~18kg·cm 필요**
- **고관절 yaw**: 지지발 마찰을 비틀며 몸을 회전시킨다.
  `μ·m·g·r = 0.6 × 1.8 × 9.81 × 0.02 ≈ 0.21 N·m ≈ 2.2 kg·cm` (TPU 발바닥 μ 0.6, 유효 반경 2cm 가정)
  토크로만 보면 MG90S급으로도 가능하지만, **예비품 통일과 다리 링크 강성 때문에 발목과 같은 모델로 통일**한다.
- **기울기 각**: `θ = atan(고관절 반간격 / 무게중심 높이)`. 반간격 35mm, 무게중심 120mm면 θ ≈ 16°이므로 **발목 roll 가동범위는 ±25° 이상** 필요하다.
  → **고관절 간격을 좁게, 무게중심은 낮게**가 골격 설계의 1순위 제약이다(§5).

## 5. 골격 구조 (P1S 출력 전제)

```
             [머리 셸]          ← 외피만 (heebin Blender). 내부: 표정/카메라 결정 후
                 │ CH0 yaw / CH1 pitch (MG90S, 반대편 베어링 지지)
   ┌─────────────┴─────────────┐ ← 몸통 상단 브리지: 목·어깨 서보 마운트
 CH2-5 어깨/팔꿈치    RPi4+HAT 세로 실장(등쪽), Board A
   │       몸통 측판 2장 (PETG, 리브)   │
   ├──────── 배터리 트레이 (최하단) ──────┤ ← 무게중심 낮춤
   └─[CH6 hip yaw]────────[CH7 hip yaw]─┘ ← 골반 판: 서보 세로 실장, 출력축 아래
          │ 짧은 링크                │       고관절 간격 최소화 (§3)
     [CH8 ankle roll]       [CH9 ankle roll] ← 양쪽 지지 (horn + 반대편 베어링)
     ▔▔▔ 큰 발 (TPU 밑창) ▔▔▔   ▔▔▔▔▔▔▔▔▔▔
```

- **하중 경로**: 발 → 발목 브래킷 → 링크 → 고관절 서보 → 골반 판 → 측판. **외피는 하중을 받지 않는다.**
- **양쪽 지지 필수인 축**: 발목 roll(최대 하중), 고관절 yaw(링크 굽힘), 목. 반대편 베어링은 MR85/608 계열(재고 확인).
- **외피 고정**: heat insert(M2/M3) boss 또는 자석으로 골격에 건다. 관절부 외피는 회전축이 곡면 중심에 오도록 한다(heebin 외형 작업 시 요청 사항).
- **IP 경계** (`docs/skills/cadquery-modeling.md:3-6`): 외형 형상은 heebin, Claude는 골격·마운트·분할만 맡는다.

### 리스크 / 미결

1. **6V_LEG 벅 모델 미정.** Pololu D24V150F6(6V 15A)이 후보지만 존재와 스펙을 확인하지 않았다(미확인). 공식 페이지로 확인한다.
2. **입력 보호 소자 정격 부족 의심.** Q1 IRLML6402(SOT-23)의 연속 정격은 수 A 수준으로 기억하나 datasheet로 확인하지 않았다(미확인). 기존 10A 퓨즈 설계에서도 문제가 될 수 있다. 실보행 입력 전류는 ~16A(추정)이므로 **고전류 P-MOSFET 또는 ideal-diode 컨트롤러로 교체**를 검토한다.
3. **3-in-1 카메라 질량·크기 미확인.** 머리에 넣으면 머리 질량이 커져 목 pitch 서보(MG90S)와 보행 안정성에 직접 영향을 준다. 몸통 배치 또는 소형 카메라 대체를 결정해야 한다.
4. **CAD 도구 미정** (`docs/skills/cadquery-modeling.md:11`). 권장은 **CadQuery**: 코드 기반이라 파라미터로 공차를 조정할 수 있고, Claude가 직접 생성하고 검증할 수 있다.
5. **일정.** 보행 난이도가 올라 W8 게이트("1주 내 미안정 시 v2")에 걸릴 가능성이 크다(추정). 실보행용 골격 가조립과 IMU를 앞당겨 W4~W5에 리스크를 조기 소진한다.
